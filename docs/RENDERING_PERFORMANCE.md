# Перевірка інтерактивної сцени

Локальний замір 08.09.2026: Chromium headless, viewport 1440×1000, DPR 1, відкритий кран. Три секунди спостереження після 2,5 секунди прогріву. Фінальний замір виконано на production-збірці. Це порівняння в одному середовищі, а не гарантія FPS для всіх пристроїв; початкова компіляція WebGL-шейдерів у нього не входить.

| Показник                  | До оптимізації |   Після |
| ------------------------- | -------------: | ------: |
| Середня частота кадрів    |          4 FPS |  60 FPS |
| Медіана інтервалу кадру   |         250 мс | 16,7 мс |
| 95-й перцентиль інтервалу |       266,8 мс | 16,8 мс |
| Медіана JS-роботи рендера |         1,9 мс |  0,3 мс |
| Команди малювання за кадр |            163 |      10 |

Попередня версія повторно малювала всю модель під час руху води. Прозорість через transmission додавала проходи рендера, а дуже малі зміни кута ручки продовжували оновлювати тіні. Тепер нерухомий корпус, керамічна чаша, опорна темно-синя тумба, сіра кам’яна стільниця, підлога, сіра плитка стіни й VSM-тіні один раз записуються в HalfFloat-текстуру з глибиною та оновлюються після зміни розміру. Кадр анімації складається зі збереженого фону, шести деталей ручки та трьох груп води; бризки й остання залишкова крапля малюються одним instanced викликом. Вода використовує збережене зображення для наближеного ефекту заломлення, а деформацію струменя й затухання хвиль обчислює шейдер. Камера й корпус залишаються нерухомими.

Команди WebGL рахувалися через `drawElements`, `drawArrays` і їхні instanced-варіанти. Середня частота кадрів обчислюється за часовими позначками кадрів, у яких відбувалося малювання; медіана в таблиці стосується інтервалів між кадрами та JS-роботи рендера. Сирі результати порівняння є у комплекті `../verification/water-perf-before.json` та `../verification/water-perf-production.json` відносно кореня проєкту.

Регресійний браузерний тест у `tests/interactive-plumbing.spec.ts` перевіряє бюджет до 20 команд на кадр після прогріву. FPS не є жорсткою CI-умовою, оскільки він залежить від GPU та навантаження середовища.

```bash
npm run build
npm run test:e2e
npm run test:water
```

Чотирнадцять тестів у `scripts/test-water.mjs` перевіряють балістичний час падіння з прискоренням, неперервність потоку та звуження струменя, відсікання біля сопла при закритті й подальше падіння залишку. Також перевіряються баланс отриманого, злитого й збереженого об’єму, нелінійна залежність рівня води від профілю круглої керамічної чаші, наповнення та стік, часткове відкриття, швидкі зміни, затухання хвиль і одна остання крапля, зокрема після поступового закривання. Окремі сценарії охоплюють reduced motion, некоректні значення та стабільність моделі за різних часових кроків.

`lib/plumbing-fluid.ts` використовує початкову швидкість 1,1 м/с і прискорення 9,81 м/с², окрему затримку для кожної висоти та стік, що залежить від рівня води. Це обмежена фізично вмотивована модель для анімації, без повного розрахунку гідродинаміки або калібрування реального сантехнічного обладнання. Після завершення руху ручки, падіння залишку й спорожнення чаші цикл рендера зупиняється; поза екраном і в прихованій вкладці він призупиняється.
