# Architecture — LocalSEO Starter

- **App Router and static pages:** Next.js 16.3.4, React 19.2.8, and TypeScript render seven public pages at build time; the contact POST endpoint runs on the server.
- **Typed Polish content:** `content/site.ts`, `services.ts`, `pages.ts`, `ui.ts`, and `form.ts` own business details and page copy; `visuals.ts` owns service image paths and alternatives, and `interactive-art.ts` owns the hero's control and status text without a CMS or database.
- **Service routing:** `/uslugi/[slug]` uses `generateStaticParams` for the three declared services. Unknown slugs reach an explicit `notFound()` check and return real 404 responses; they never create new service content.
- **Shared presentation and 3D interaction:** `interactive-plumbing.tsx` exposes the illustration as a focusable ARIA slider for direct drag, arrow keys, and Home/End, with one visible hint. The lazy-loaded Three.js renderer caches the fixed washstand's colour, depth, and VSM shadows; `plumbing-fluid.ts` models ballistic transport, continuity-based stream radius, and a nonlinear ceramic-basin volume balance, rendered in three water batches by `plumbing-water.ts`. The body and camera remain fixed; settled frames stop, hidden/offscreen states pause, reduced motion is static, and WebGL failure retains poster-based drag/keyboard control.
- **SEO ownership:** `lib/seo.ts` builds unique metadata, absolute canonical and social URLs, and Plumber, Service, BreadcrumbList, and FAQPage objects; the JSON-LD component serializes them safely into initial HTML.
- **Crawl controls:** metadata routes produce robots.txt and a seven-page sitemap; environment-based noindex mode removes sitemap entries while allowing crawlers to read the noindex directive.
- **Form boundary:** a client form and shared validator feed `POST /api/contact`, which applies content-type, origin, size, field, and honeypot checks before redacted demo logging or an optional HTTPS JSON webhook.
- **Optional measurement:** client analytics remain inactive without a valid GA4 ID and opt-in consent; scoped page_view and click_call events exclude form data, while generate_lead requires confirmed webhook acceptance.
- **Local assets and map:** Manrope Latin / Latin Extended are served through next/font/local, UI icons use licensed Lucide assets, two 900×900 WebP posters capture the actual authored 3D scene, and three service SVGs were manually authored from AI-generated concepts; a separately attributed map SVG retains all 23,288 vertices of the city's 18 district polygons dated 2014-03-31.
- **Verification and deployment:** ESLint, TypeScript, production build, Playwright with axe, mocked logic tests, `npm run test:water` for fluid timing, and a reproducible mobile Lighthouse script cover the delivery; `npm run art:render` recaptures 3D posters from the local production app before a new build, and Vercel uses the standard Next.js runtime with optional environment settings and no committed secrets.
